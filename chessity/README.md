# Learn · Chessity

Окрема вкладка `#chessity`: на комп’ютері — у лівій панелі, на телефоні — перша знизу. Каталог містить 18 рівнів і 683 уроки; можна обирати будь-який рівень, переглядати пояснення з анімацією, розв’язувати вправи, користуватися підказками й зберігати зірки на цьому пристрої. Вхід не потрібний.

## Походження та межі перенесення

Назви, структура, позиції FEN, варіанти PGN, тексти й ілюстрації взяті з наданого користувачем застосунку Chessity та відповідей його сервісу. Це матеріали **Chessity**, а не новий відкритий банк задач; на них не поширюється ліцензія нашого коду. Оригінал: https://www.chessity.com/.

Локальна копія містить 904 вихідні приклади пояснень і 682 отримані завдання — по одному доступному серверному завданню на урок. Для уроку 1858 сервер повертав помилку; його мікс складається з трьох доступних завдань того самого рівня, джерела вказані в JSON. Після відбору придатних до гри прикладів і вилучення повторів доступні **1533 вправи**.

Це самостійна вебреалізація Learn, а не повна копія серверного банку чи всіх ігрових режимів застосунку. Адаптивний підбір нових серверних завдань, рейтинг і синхронізація з Chessity відсутні. Інтерфейс, назви уроків і початкові пояснення українські; частина оригінальних пояснень залишилася англійською. Короткі маршрути з монетами дозволяють різні безпечні шляхи до прапорця. Звичайні вправи перевіряються за доступними правильними варіантами PGN. Завершення з переглядом розв’язання не дає зірок.

`data/` містить лише навчальні поля. Паролі, токени, ідентифікатори користувача та приватний прогрес не зберігаються й не публікуються. Новий прогрес записується до `localStorage` під ключем `chk:chessity:v1` і не передається на сервер.

## Технічна частина

- `app.js`, `style.css` — каталог, вправи й переходи; спільні дошка та пояснення — `shared/board.js` і `shared/guide.js`.
- `model.js` — навчальні позиції, монети, початкові поля, PGN та шахові правила.
- `engine.js` — локальна збірка chessops (GPL-3.0); джерело `engine-src.js`, збирається через `npm run build`.
- `chessground.base.css` — стилі Chessground (GPL-3.0), копія з установленого npm-пакета; шахові дошки й фігури використовують спільні ресурси проєкту.
- `npm run check:chessity` — браузерна перевірка каталогу, пояснення, справжніх ходів, зірок і переходів на двох телефонах та комп’ютері. Включена до `npm run check`; перевірки моделі й усього каталогу — у `tools/test/chessity.test.mjs`.
