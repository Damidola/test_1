# Android APK

[Скачать Chessity v230](https://damidola.github.io/test_1/downloads/Chessity_OFFLINE_AUDIO_v230.apk)

Общий SoundPool для коротких звуков, до четырёх временных плееров для длинных записей, восстановление после ошибки декодера. Исходные звуковые файлы сохранены. Устанавливать поверх предыдущей версии для сохранения прогресса.

Проверки: 152 запуска 38 используемых звуков; 248 запусков всех 62 файлов; 80 повторов с паузами и принудительной ошибкой декодера. Дополнительно 80 повторов на Android-эмуляторе с записью аудиовыхода: сигнал присутствует в начале и конце записи. Полный интерфейс Flutter на физическом телефоне этим тестом не проверен.
